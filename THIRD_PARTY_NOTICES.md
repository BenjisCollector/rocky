# Third-party notices

Rocky combines ideas and, in places, adapted code from three MIT-licensed projects. Their authors deserve the credit.

- browser-use/jev-ultrafast (MIT) https://github.com/browser-use/jev-ultrafast : the one-request operation-plus-target loop.
- kevinbadi/jev-voice (MIT) https://github.com/kevinbadi/jev-voice : the voice front end, the "addressed" gate, and select-instead-of-generate text spans.
- awlevin/typesafe-computer-use (MIT) https://github.com/awlevin/typesafe-computer-use : dry-run by default, confidence floors, stall detection, replayable run folders, and the rule that platform calls live in one file.
